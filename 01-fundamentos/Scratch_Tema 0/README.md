## 💡 Conceptos Clave Asimilados
*   **Eventos:** Control de ejecuciones paralelas al presionar teclas o banderas.
*   **Bucles:** Implementación de ciclos infinitos (`por siempre`) y finitos.
*   **Condicionales:** Estructuras lógicas para ramificar el comportamiento de los objetos.
