# 01. Fundamentos de Programación

Este módulo contiene los conceptos iniciales y los bloques fundamentales indispensables para el desarrollo de software moderno. Está dividido en dos enfoques educativos complementarios:

## 📂 Estructura y Navegación del Módulo

Haz clic en cualquiera de los bloques para acceder directamente a sus guías, ejercicios resueltos y material de apoyo:

*   **[🐱 Ir a Programación Visual con Scratch](./Scratch_Tema%200/README.md):** Introducción a la lógica algorítmica mediante bloques interactivos, control de flujo y eventos.
*   **[📝 Ir a Fundamentos de Pseudocódigo](./PSEUDOCODIGO_Tema%201/README.md):** Diseño estructurado de algoritmos orientados a la optimización, tipado de variables y control de excepciones (PSeInt).

---

## 🎯 Objetivos de Aprendizaje
*   Desarrollar un pensamiento analítico sólido para la resolución y descomposición de problemas de software.
*   Comprender y dominar el ciclo de vida de los datos mediante variables y operaciones aritméticas.
*   Implementar estructuras condicionales avanzadas y flujos lógicos secuenciales estables.
