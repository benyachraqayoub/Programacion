# Ejercicio 4 — Mostrar datos personales almacenados en variables

Programa que guarda el nombre, la dirección y el teléfono en variables y muestra sus valores en líneas separadas. Sustituye los valores de ejemplo por tus propios datos.

---

## 📝 Algoritmo en Lenguaje Natural

1. **Inicio.**
2. Crear las variables `nombre`, `direccion` y `telefono` de tipo `String`.
3. Asignar a cada variable su valor correspondiente.
4. Mostrar por pantalla el valor de cada variable en una línea separada.
5. **Fin.**

---

<details>
<summary><b>👁️ Ver solución en Java (Código)</b></summary>

```java
public class Principal {
    public static void main(String[] args) {
        String nombre = "Ayoub Ben Yachraq";
        String direccion = "Tu dirección";
        String telefono = "Tu teléfono";

        System.out.println(nombre);
        System.out.println(direccion);
        System.out.println(telefono);
    }
}
```
