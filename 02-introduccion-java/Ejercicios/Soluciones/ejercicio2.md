# Ejercicio 2 — Mostrar nombre, dirección y teléfono

Programa que muestra el nombre, la dirección y el teléfono en líneas separadas. Sustituye los valores de ejemplo por tus propios datos.

---

## 📝 Algoritmo en Lenguaje Natural

1. **Inicio.**
2. Mostrar el nombre por pantalla.
3. Mostrar la dirección en una línea nueva.
4. Mostrar el teléfono en una línea nueva.
5. **Fin.**

---

<details>
<summary><b>👁️ Ver solución en Java (Código)</b></summary>

```java
public class Principal {
    public static void main(String[] args) {
        System.out.println("Ayoub Ben Yachraq");
        System.out.println("Tu dirección");
        System.out.println("Tu teléfono");
    }
}
```
