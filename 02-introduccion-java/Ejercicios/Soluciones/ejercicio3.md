# Ejercicio 3 — Mostrar el nombre almacenado en una variable

Programa que guarda un nombre completo en una variable de tipo `String` y muestra su valor por pantalla.

---

## 📝 Algoritmo en Lenguaje Natural

1. **Inicio.**
2. Crear la variable `nombre` de tipo `String`.
3. Asignar el nombre completo a `nombre`.
4. Mostrar el valor de `nombre` por pantalla.
5. **Fin.**

---

<details>
<summary><b>👁️ Ver solución en Java (Código)</b></summary>

```java
public class Principal {
    public static void main(String[] args) {
        String nombre = "Ayoub Ben Yachraq";
        System.out.println(nombre);
    }
}
```

</details>
